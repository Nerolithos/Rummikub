# Rummikub · 拉密牌会客厅

可直接运行的单机浏览器游戏，采用 With a Twist 的 112 张牌版本。原生 JavaScript、CSS、Web Worker；无构建步骤、无 npm 依赖。

## 运行

需要 Node.js 20 或更新版本：

```sh
npm start
```

打开 http://localhost:5173 。可使用 `PORT=8080 npm start` 更换端口。端口被占用时自动尝试后续端口（最多 20 次），请打开终端实际打印的地址。服务器仅监听本机地址。不要双击 HTML（ES 模块与 Worker 需要 HTTP 服务）。字体为可选在线资源，断网自动回退到系统字体，游戏逻辑不依赖网络。

```sh
npm test       # 规则、状态转换、AI 完整对局模拟
npm run check  # JavaScript 语法检查
```

## 已实现

- 2–4 人同机模式、单人对战 AI；玩家名、60/120/180 秒或不限时。
- 随机先手，每人 14 张；提交和抽牌立即移除手牌 DOM。交接至少 2 秒，下一位主动确认后开始计时。
- 选牌、多选、拖放、插入、拆组、合组、收回本回合的牌；按颜色或数字排序。
- 撤销一步（含 Ctrl/Cmd+Z）、撤销整回合、AI 出牌建议。
- 30 分首次亮牌、功能牌验证、牌张身份与守恒检查、结束时所有牌组合法性检查。
- 超时原子回滚、抽牌直接结束、空池连续停牌终局、零和单局计分、并列最低牌值结算。
- 自动保存已提交状态，刷新后通过大厅继续并重新交接。当前未提交草稿不保存；恢复回合重新计时。
- 响应式布局、减少动态效果偏好支持、键盘按钮、功能牌与牌色读屏标签。

## 操作

1. 按出牌顺序依次点击牌，选中牌会上抬；点击「新建牌组」打出。
2. 点击已有牌组中任意 `+` 插入到该处。拖到牌的左／右半侧可插入其前后，金色标记显示落点；拖到牌组空白处则追加到末尾。组内选一张可点「左移／右移」，选两张可点「交换两张」。选牌、放牌和撤销会保留牌桌及页面滚动位置。
3. 从桌面选牌后点「新建牌组」可以拆分组合；桌面原有牌不能收入手牌。
4. 牌组上方显示合法性，右侧显示整个回合能否提交。提交失败保留草稿，继续修改即可。
5. 「抽 1 张并结束」会放弃全部草稿并抽牌；抽到的牌留待下一回合。
6. 「给我一点灵感」从回合开始的状态生成建议草稿，可以撤销或继续调整。

## 规则来源与选择

官方来源：[Twist 说明书](https://rummikub.com/wp-content/uploads/2019/12/Twist-International.pdf)、[官方规则页](https://rummikub.com/rules/)。采用 104 数字牌和 8 功能牌的说明书清单，不采用产品营销页面中有歧义的数量描述。

完整玩家说明内置于「游戏规则」。下列是本作的明确约定，而非声称官方涵盖了全部边界：

- 随机先手替代实体抽牌比大小；单局结算，不累计赛事轮次。
- 按本桌选择，双数 Joker 计两个牌位，组合最低数量按牌位而非实体牌计算。因此「13＋双数 Joker」可作为三色 13 群组，计 39 分；普通百搭仍只计一个牌位。这与原说明书至少三张实体牌的限制不同。
- 换色牌代表切换前颜色的一个数字位置，后一个位置起变色；允许端点位置。
- 镜像按展开后的数字与颜色比较，可与百搭、双数共同使用；单侧允许一个数字位置。一组最多一张镜像牌，至少一张真实数字牌，不允许全功能牌组。
- 顺子按左到右升序摆放；镜像右半边与左半边反向。数字 1 不接在 13 后。
- 多解功能牌使用最高合法亮牌分值。功能牌移动后必须留在桌面上的合法组合里；已亮牌玩家可以重排整张桌面。
- 所有未提交的桌面变更均视为未完成操作，超时撤回并罚抽 3 张，即使草稿当时合法；无变更则抽 1 张。取消全部草稿后按无变更处理。
- 空池后所有人连续选择停牌，视为共同结束，而不是穷举证明所有人无牌可出。并列最低牌值者平分其他人的牌值差收益（可有小数）。
- 交接、重新加载恢复均重新开始完整回合时间；用于休闲同机对局，不是防作弊竞赛客户端。本地存档保存整局手牌，隐私遮罩仅用于正常轮流游玩。

## 架构与 AI

`src/engine.js` 是纯函数规则和状态引擎；`src/app.js` 管理界面、草稿、计时、交接与保存；`src/ai-worker.js` 在后台计算避免阻塞计时。策略输入会剔除其他玩家的手牌。

AI 枚举普通组合、部分功能牌组合，用有节点预算的组合搜索优先多出牌，再尝试向公共组合任意位置接牌。所有输出经过与真人相同的验证。它不穷尽多功能牌组合或任意桌面重排，提示无结果不意味着数学上无解。

## 验证

自动测试覆盖基础组合、四种功能牌、镜像展开、破冰分值、禁止首回合重排、非法牌张、回滚、抽牌、结算、AI 以及固定种子四人完整对局的每步 112 张守恒。
