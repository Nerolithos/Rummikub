# 浏览器验收（2026-10-07）

本机 Codex 浏览器，http://localhost:5173，桌面 1280px 与手机 390px。

- 开局出现交接遮罩；准备按钮先禁用，2 秒后启用，确认前手牌 DOM 不存在。
- 翻牌后显示 14 张手牌并从所选时长开始计时。
- 手动选择红 12、蓝 12、百搭，新建组合，提示 36 分可提交。
- 撤销一步恢复手牌；AI 提示生成两组共 42 分的亮牌草稿。
- 确认后切到下一人，上一位 8 张牌，手牌隐藏；下一位抽牌后手牌增至 15，牌池 84 → 83，再次交接。
- 刷新回到大厅，可继续上次已提交局面。
- 手机下检查手牌换行、牌组区、计时卡与按钮；修复大厅装饰牌与文案重叠。
- 人机模式选择 60 秒，翻牌后显示 01:00；打出孤立单牌并提交被拦截，草稿保留。

自动化规则与整局模拟测试：`npm test`。这里的浏览器验收为实际 UI 操作记录，不声称提供了跨浏览器自动化回归套件。

最终检查：60 秒倒计时自然归零后，孤立草稿撤回、玩家手牌 14 → 17、牌池 84 → 81；AI 随即自动打出 9 张并破冰，进入第 3 回合交接。刷新并恢复后 60 秒设置保留。规则弹窗正常打开和关闭。浏览器未捕获 JavaScript 错误。预览已留在大厅。
